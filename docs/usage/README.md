# Usage

For people using the plugin in their own projects.

- [install.md](install.md) — install, update, uninstall, enable for a whole repository.
- [opt-out.md](opt-out.md) — turn the plugin off, or quiet it, for one project.
- [copilot-review.md](copilot-review.md) — set up automated GitHub Copilot code review for a
  repository, which `/push` uses as its reviewer.
